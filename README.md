# VA Disability Compensation Recipients-FY 2025
This project analyzes the U.S Department of veteran affairs(VA) Disability Compensation dataset to understand the distribution of disability compensation recipients across states,counties,disability rating groups,age groups and gender
## Description
The analysis uses Python for data cleaning and Exploratory Data Analysis(EDA),followed by Power BI for interactive data visualization and dashboard development.Business Problem of this project is understanding how disability compensation recipients are distributed across geographical regions and demographic groups is important for identifying patterns and variations in the veteran population
### Dependencies
Google Colab,Jupyter Notebook,Power BI
### Tools and Technologies
*Python: Data cleaning, analysis, and visualization
*Pandas: Data manipulation and preprocessing
*NumPy: Numerical operations
*Matplotlib & Seaborn: Data visualization
*Google Colab: Python development environment
*Power BI: Interactive dashboard development
## Project Workflow
1. Data Cleaning and Preprocessing (Python)
*Inspected dataset structure, and data types
*Checked for missing values and duplicate records
*Handled missing values
*Examined outliers using the Interquartile Range (IQR) method
*Analyzed skewness in numerical variables
2. Exploratory Data Analysis (EDA)
-Performed different levels of analysis:
1)Univariate Analysis
*Analyzed the distribution of disability rating groups
*Examined recipient distribution across age groups and gender
*Identified skewness and outliers
2)Bivariate Analysis
*Compared disability rating groups with recipient counts
*Examined age and gender distributions
*Analyzed relationships between selected numerical variables
3)Multivariate Analysis
*Used correlation analysis to understand relationships between numerical variables
*Explored patterns across disability ratings, age groups, and gender
3. Power BI Dashboard
Developed an interactive dashboard to present key findings through:
*KPI cards showing total recipients and demographic figures
*Disability rating,Age group,Gender distribution
*Geographical distribution across states and counties
*Interactive filters for exploring different segments
## Conclusion:
This project demonstrates the use of Python and Power BI to transform raw data into meaningful insights. Python was used for data cleaning, preprocessing, and exploratory analysis, while Power BI helped communicate the findings through an interactive dashboard.
